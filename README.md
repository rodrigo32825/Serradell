# Serradell

Sitio estático de una página para preescolar y primaria. Abre `index.html` en un navegador para revisarlo.

## Publicar en GitHub Pages

1. En **Settings → Pages**, elegir **Deploy from a branch**, `main` y `/ (root)`.
2. La dirección será `https://rodrigo32825.github.io/Serradell/` una vez que GitHub Pages esté activo.

## Antes de darlo por definitivo

- Reemplazar el monograma tipográfico por el logotipo oficial.
- El botón de contacto apunta a la cuenta de Instagram facilitada por la escuela: `@serradell_`.
- Confirmar el contenido institucional y las fotografías que la escuela autorice publicar.
- Cuando exista dominio, configurar la dirección personalizada en GitHub Pages y después preparar `sitemap.xml`, `robots.txt` y Search Console para esa URL.
